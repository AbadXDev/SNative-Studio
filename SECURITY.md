# Seguridad

SNative Studio 0.1.0 no tiene todavía un canal de contacto confirmado para avisos de seguridad. No hay una dirección de correo que se pueda indicar aquí.

Cuando exista un canal privado, describe el problema sin adjuntar:

- `prod.keys` ni otras claves
- archivos NSP, IPA o datos de juegos
- registros que incluyan rutas personales
- tokens, contraseñas u otros secretos

Si el único lugar disponible es público, omite esos archivos y cualquier valor secreto. Indica el componente afectado y la versión 0.1.0.
